# Esfera de Mérito — Renault Master 3D

## Model specification

- Base: 2023 Renault Master L2H2 panel van
- Exterior: clean bright white
- Black unpainted plastic side mouldings, handles and bumpers
- Standard wheels, headlights and tail lights
- Interactive web-ready 3D model
- Required export: GLB/GLTF (preferred), with FBX/OBJ compatibility where possible
- PBR textures: Diffuse/Base Color, Normal, Roughness
- Target texture resolution: 4K
- UV-mapped graphics applied seamlessly to the vehicle body panels
